# 六年級・複習筆記

繁體中文、靜態前端、無登入與模型服務的國小六年級複習網站。各科目標200題；有效題數以網站首頁及 `docs/bank-summary.json` 為準。逐題來源、原刊答案與排除狀態見 `docs/question-audit.json`，目前進度及部署限制見 `docs/DELIVERY.md`。

## 啟動

需求：Node.js 22.18+（或24+）與 npm。

```powershell
npm ci
npm run dev -- --port 5173
```

瀏覽 `http://127.0.0.1:5173/`。`node_modules` 不包含在交付壓縮檔內。此工作目錄已安裝依賴。

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

`dist/` 是可部署至一般靜態主機的建置結果。請以 HTTP 伺服器開啟，不能直接雙擊 `index.html`。不同網域或連接埠的 localStorage 相互獨立；切換前請匯出備份。

若安裝時遇到本機代理憑證問題，使用已支援系統憑證的 Node.js 與 `--use-system-ca`，不要停用 TLS 憑證驗證。

## 個人複習工作台

- 首頁、逐題練習、模擬考、錯題本、單字、成績六個入口；觀念地圖與題庫來源另外保留。
- 進度自動保存於目前瀏覽器，免手動切換學習者。沿用舊版最後使用的資料檔，保留既有作答；不同瀏覽器使用者設定檔各自保存，無跨裝置同步。
- 可選六上／六下、考試階段、全科／單科，各科再獨立選來源版本及勾選主題。
- 基礎優先基本題，進階優先應用題；自動根據各科最近10筆已完成作答決定下一回合偏好。題型偏好不是校準過的難度或能力等級。
- 逐題練習最多5題；隨手練與弱點特訓最多10題；模擬考最多20題，少題維持實際數量。全科輪流選有題目的科目，不跨範圍填補空缺。
- 弱點特訓依錯誤及待複習紀錄，另可專練一個觀念。考前必殺是個人弱點優先，沒有高頻統計或押題。
- 18個英文補充字詞、3個主題，提供翻卡及來源拼字核對；單字紀錄不灌入段考試題分數。
- 五科與六向度作答圖依已完成作答計算；未作答為尚無資料，圖表判讀／整合閱讀尚無可評估試題。

## 依教材範圍與觀念練習

依來源學年度及原卷四個考試階段整理版本範圍、單元及觀念。選擇考試階段、科目與版本範圍後，可以直接練某觀念的基本題或應用題。已核驗原題逐一分類，沒有新增生成題或答案。基本題／應用題是本站編輯分類，不是官方難度或出題頻率；空缺題型、未確認版本及尚缺完整目次均明示。資料見 `src/study-plan.ts` 與 `docs/study-plans.json`。

## 已實作

- 依六上第一次段考／六上期末／六下第一次段考／六下期末篩選，再選科目與單元；每題可查看原卷階段及學年度。
- 五科入口、已收錄題數、具名單元及尚未收錄原因。
- 逐題5題、隨手練10題、模擬考20題；依所選科目與範圍組卷，不重複題目，優先未練與待複習題。
- 逐題確認後鎖定、以保存來源答案比對；不呼叫 AI 判分或產生解析。
- 小測驗可返回修改；交卷前不顯示答案；未答交卷再次確認。
- 「這個還沒教過」不計錯；「還不懂」及答錯加入待複習。
- 兩個不同完成回合連續答對才移出待複習；再錯或標記還不懂重設。
- 本機問題標記停止該題後續出題，不假裝向外回報。
- localStorage 保存設定、未完成回合、題目及答案快照、歷史、錯題、問題標記。
- 完成回合才計入歷史，防重複交卷；備份匯入深層驗證及取代確認。
- 匯入不能植入未知題目、修改標準答案或補寫詳解。只接受內建已核對題目的已知版本。
- 手機版、鍵盤作答、可見焦點、原生對話框焦點限制。

## 程式結構

- `src/main.tsx`：首頁、練習、小測驗、結果、錯題、進度、來源、備份。
- `src/engine.ts`：確定性判分、單科／全科回合、錯題規則、備份驗證。
- `src/training.ts`、`src/LearningHub.tsx`：範圍組卷、分科程度偏好、弱點與作答圖。
- `src/vocabulary.ts`、`src/VocabularyPage.tsx`：有來源的補充字卡與獨立自測紀錄。
- `src/bank.ts`：已核對題目、原始來源與使用依據。
- `src/types.ts`：資料結構。
- `tests/engine.test.ts`：完成開發後集中撰寫的功能測試。
- `docs/`：交付紀錄、完整題庫JSON、逐題來源核對與來源檔案雜湊。

## 更新題庫

新增題目先維持 `draft`，完成題本、同版本標準答案、必要附件、使用條件與更正公告核對後才設為 `sourceChecked`。有疑義設為 `excluded`，不要自行修正來源答案。更改內容或答案必須提高 revision，並保留舊 revision 為 excluded，讓已知舊版本備份仍能驗證；不要覆寫舊回合快照。內建題庫新增非文字附件前須擴充呈現及驗證邏輯，目前支援獨立文字選擇、是非及有原刊唯一答案的填答題。完整多格題保留整題，以全形分號按順序輸入；不拆空格增加題數。填答比對只處理文字格式及等值數字表示，不執行使用者算式，也不生成學科答案。

## 發布

GitHub Pages部署流程見 `.github/workflows/pages.yml`；推送main後先執行測試與建置，再發布dist。GitHub儲存庫須開啟Pages、Source選GitHub Actions。Vite使用相對資源路徑，適用儲存庫子路徑；舊qa-mobile連結轉往相同子路徑的首頁。

目前題庫有效969題：國語200、英語169、數學200、自然200、社會200。英文距200仍缺31題，首頁如實顯示。部署版紀錄只存於訪客瀏覽器，與本機127.0.0.1的紀錄分開；轉站前可先在成績頁匯出JSON備份，再於公開站匯入。
