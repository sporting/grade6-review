# GitHub Pages 簡單入口

固定帳密的前端入口，配合robots meta與robots.txt要求搜尋引擎不要索引。題目模組在通過入口後才載入，減少一般訪客直接看到內容。

GitHub Pages專案站的robots.txt位於專案路徑，未必控制網域根目錄的爬蟲規則；頁面的noindex標記是本次主要索引設定。既有搜尋結果不會保證立即移除。

這不是伺服器端身分驗證：GitHub Pages仍為公開靜態網站，原始碼與資產可直接取得。專用密碼以附鹽SHA-256雜湊比對，驗證值隨網站公開；熟悉開發工具的人可以繞過入口。robots設定亦僅為爬蟲自願遵守的指示。登入不能作為受限出版社題庫上傳的授權依據。

GitHub入口帳密獨立產生，絕不讀取或沿用家庭伺服器的密碼。明文交付檔保存在Git忽略的.private目錄，不進入網站或公開文件。

預設可記住瀏覽器30天，亦可取消勾選。登出只清除入口通行狀態，不清除成績、錯題或未完成回合。重新登入會讀取最新作答紀錄。同一帳號不會同步不同裝置資料。

手機登入直接讀取實際表單值，以支援未觸發change事件的密碼自動填入。帳號預填、密碼可顯示核對；輸入首尾空白會略過。記住登入同時寫入localStorage及同專案路徑的Secure/SameSite Cookie；其中之一受限時使用另一個。sessionStorage保留目前分頁的通行狀態。若兩種長期儲存皆失敗，頁面會提示，而非默默承諾記住。重新開啟時若有未完成回合，直接顯示原題。

測試包含DOM模擬的自動填入、重開頁面，以及Cookie/儲存失敗情境，不能替代手機Safari或Chrome實機驗證。私密瀏覽、清除網站資料及瀏覽器自身清理政策仍可能移除登入或作答紀錄。
