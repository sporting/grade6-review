## 比較兩種互動模型

1. 每回合先走五步設定精靈：首次使用容易理解，但回訪與錯題重練需要反覆穿越步驟；中斷恢復較繁瑣。
2. 持續保留的複習工作台：主要設定和入口同頁，各科細節可展開；每次回訪可接續回合，快速改範圍。設定較多，透過「主要設定常見、各科細節按需展開」減少負擔。

選擇第二種。色彩沿用森林綠、霧白與分科柔色，首頁以「這次的複習」範圍便箋作識別，不使用無根據的排名、會考級分或精熟度數字。

## 資訊架構與核心流程

- 持續導覽：首頁、逐題練習、模擬考、錯題本、單字、成績。題庫來源放頁尾，觀念地圖從首頁進入。
- 新／返回學生：選匿名學習檔案A/B/C → 設定進度、考試、科目、程度 → 必要時各科選版本及主題 → 開始練習 → 完成與核對 → 成績與弱點 → 下次特訓。
- 回合中斷：儲存題目快照、答案與位置；回首頁可接續，開始新回合前先完成目前回合。切換學習檔案後保留各自未完成回合。
- 未涵蓋範圍：顯示缺科與0題，提供調整設定入口，不跨階段、出版社或未勾選主題補題。
- 無弱點紀錄：先逐題練習；沒有預設弱點。已移出待複習且最近作答正確的題目，不永久受歷史錯誤追罰。
- 六上、六下為範圍篩選，不假定全國各校相同章節切分。現有來源的教材年度與未知版本仍明示。

自動程度依目前題池各科最近10筆已完成作答：少於5筆偏基礎；正確率低於60%偏基礎、80%以上偏應用，其餘標準。只影響下一回合，不在測驗途中換題。全科組卷先確保各有題科目的輪流分配，再按各科內部的程度與弱點優先序取題。

六向度為本站題型觀察：概念辨識、語文運用、數量運算、情境推理、圖表判讀、整合閱讀。不是參考站的能力評分模型，也不是標準化診斷。圖表與整合閱讀目前沒有合格題目，保留未評估。

無模型服務、不傳送兒童作答資料、不新增姓名或學校資料欄位。匿名學習檔案是同瀏覽器內的資料區隔，不是有密碼的帳號隔離。

## 驗證任務

工程驗證，不冒稱真實學生研究。成功條件是實際題池及回合結果符合設定。

1. 不知道程度的學生準備六上第一次段考：查看缺科，開始一回合，確認不出現六下題。
2. 同學與家人共用裝置：在隔離QA來源用A作答，切B確認空紀錄，切A恢復回合。
3. 自然學生選南一並只勾簡單機械：開始進階練習，確認只出範圍內應用題；錯題產生特訓，再答對兩回合可移出。
4. 開始全科模擬考，中途回首頁再恢復；答案只在交卷後呈現。
5. 單字拼字答錯加入單字待複習；段考試題歷史數不變。
6. 查看沒有資料的雷達向度，確認顯示尚無資料。

## 驗證後修正

- 學生選單科後，展開各科設定時預先顯示該科，避免仍停在先前另一科。
- 單字自測開始後自動聚焦拼字欄位，避免在長字卡頁下方新增表單卻看不到。
- 單科觀念特訓提供直接入口，不只列出統計。
- 分科自動安排，避免某科的正確率決定其他科的題型偏好。
- 弱點依未解除的錯誤／待複習判斷，不以歷史總錯誤永久追罰。
- 390px底部六個入口均可見；基本觸控區仍至少44px。
